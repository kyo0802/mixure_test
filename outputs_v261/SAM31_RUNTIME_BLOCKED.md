# SAM31_RUNTIME_BLOCKED

Official `facebook/sam3.1/sam3.1_multiplex.pt` access and SHA-256 validation succeeded. The block is local runtime feasibility: official SAM 3.1 code forces Flash SDPA when `use_fa3=False`, but the Windows PyTorch wheel reports `No available kernel`; the recommended FlashAttention 3 wheel imports but fails on the RTX 5070 Ti with `no kernel image is available for execution on the device`. A project-local math-SDPA fallback runs, yet the matched-box eight-frame test takes 183.327 s for propagation and peaks at 22,840,581,120 PyTorch allocated bytes, above physical GPU memory. The explicit-instance point fallback takes 130.884 s and returns a nonempty mask on only one of eight frames. The official 16-slot checkpoint cannot be loaded with `multiplex_count=1`; `max_num_objects=1` does not resolve long-window cost. Under the specification's stop rule, full seven-video inference was stopped.
