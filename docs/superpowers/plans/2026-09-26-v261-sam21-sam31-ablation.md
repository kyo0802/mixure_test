# V2.6.1 SAM 2.1 vs SAM 3.1 Ablation Implementation Plan

> **For agentic workers:** Execute inline in this task. Preserve all prior outputs and code. Steps use checkboxes for tracking.

**Goal:** Compare the official SAM 3.1 checkpoint with the existing SAM 2.1 target continuity pipeline on the frozen seven-video FindMind task, or document the official checkpoint blocker without inventing results.

**Architecture:** Freeze the V2.6 input and decision manifests, review the official SAM 3.1 predictor, and audit a separate runtime. The checkpoint-access gate precedes all SAM 3.1 integration and inference. If it passes, matched target prompts feed two adapters with a common observation schema; predictions are hashed before manual review and measured on the same GPU. If it fails, produce an explicit blocked report and `INSUFFICIENT_EVIDENCE` recommendation.

**Tech Stack:** Python 3.12, PyTorch/CUDA, official Meta SAM 2 and SAM 3 repositories, Hugging Face Hub, OpenCV, pytest, Matplotlib.
