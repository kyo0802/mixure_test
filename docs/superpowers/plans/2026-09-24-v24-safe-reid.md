# V2.4 Safe Long-Gap Re-ID Implementation Plan

> **For agentic workers:** Implement inline. Keep V2.1–V2.3 immutable.

**Goal:** Test whether a trusted phone appearance bank safely distinguishes later phone-like candidates without GT during inference.

**Architecture:** Read frozen V2.3 registry, V2.2 SAM masks, and source video. Extract normalized MobileNetV3 Small embeddings from trusted YOLO+SAM views into an isolated cache. Use early Task2 track22→43 and Task1 later desk-phone controls to freeze gates, then score held-out Task2 candidates. Merge only after an unambiguous `MATCH`; otherwise keep provisional entities and appearance memory separate. A separate evaluator reads GT after the inference audit is frozen.

**Tech Stack:** Python 3.12, torchvision 0.25, MobileNetV3 Small ImageNet weights, OpenCV, NumPy, pytest.
