# SAM 2.1 Smartphone A/B Implementation Plan

> **For agentic workers:** Execute inline. This plan covers the small Phase 1 experiment only.

**Goal:** Compare frozen V2.1 local smartphone observations with official SAM 2.1 video propagation on the same reviewed frames.

**Architecture:** Keep V2.1 artifacts read only. An inference module reads only video and frozen YOLO/track artifacts, writes SAM observations and logs to `outputs_v22`. A separate evaluator reads the existing GT and produces A/B metrics and figures.

**Tech Stack:** Python 3.12, PyTorch 2.10 CUDA 12.8, official Meta SAM 2 commit `2b90b9f5ceec907a1c18123530e92e794ad901a4`, SAM 2.1 hiera small, OpenCV, matplotlib.
