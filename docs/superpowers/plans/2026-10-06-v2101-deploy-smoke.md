# FindMind v2.10.1 Deployment and Smoke Test Implementation Plan

> **For agentic workers:** Execute this plan inline in the required order. Preserve the existing v2.9.7 baseline and do not start both model servers concurrently.

**Goal:** Freeze the current V297 system, deploy exactly Nemotron Nano 12B v2 VL and VideoLLaMA3-7B on the local RTX 5070 Ti, and report strict Stage-0 outcomes.

**Architecture:** Keep the v2.9.7 code, model configuration, and Qwen outputs immutable. Put cache-key helpers, new inference environments, deployment configurations, smoke inputs/results, and the final report in isolated v2.10.1 paths. New VLMs remain non-authoritative experiments with no connection to identity or Memory Graph write paths.

**Tech Stack:** Git annotated tag and SHA-256 manifests; Python/pytest; WSL2/Linux CUDA serving through vLLM or SGLang when supported; local Hugging Face model checkpoints; deterministic JSON-schema-constrained inference.
