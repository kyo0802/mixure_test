## 約兩分鐘的展示

1. 選「錄製結果 Demo」，記憶選擇 `test8.mp4`。這是已處理的真實影片，不會重新跑 GPU。
2. 首頁點 **我要出門了 / I'm Leaving**。手機、鑰匙、錢包起初都需要本人確認。
3. 如已有上一場展示，點 **開始新檢查 / New Check**。保持「展示檢查」勾選，清楚表示不是實際攜帶證明。
4. 指出手機有影片歷史線索，鑰匙與錢包沒有相關可用觀察；三件仍未確認，沒有說「你忘帶」。
5. 點手機卡片的 **尋找 手機 / Find**。同一份記憶會自動搜尋手機，展示 13.8 秒桌面相關候選。
6. 看原片框、區域、時間和不確定性；展開 **查看原始影格與引用** 看完整證據。這不是現在位置或使用者同一支手機的保證。
7. 點 **返回出門檢查**，仍是三件未確認。現在按手機的 **我已帶妥**，剩兩件；可按 **撤銷確認** 示範可逆性。
8. 逐一明確確認全部物品，出現本次檢查完成訊息。這是手動清單完成，不是影像證實已隨身攜帶。
9. 展開 **檢視之前的檢查** 可查看舊紀錄。點 **開始新檢查** 準備下一場；不會刪 Graph，也不會沿用剛才勾選。

目前已保留一份完成的展示紀錄與一份新的三件未確認檢查，方便直接操作。

## 調整必帶物品

在首頁或離開頁展開 **設定必帶物品 / Edit essentials**：

- 名稱、搜尋類別、啟用開關修改後按儲存。
- 可新增或移除物品。常用類別為 phone、keys、wallet、bottle、cup；其他類別可自行填寫，但不保證已有感知證據。
- 設定只套用到下一次新檢查；當次與歷史清單快照不被改寫。
- 預設清單只是設定範例，不表示影片中已看見這些物品。

若要記錄真正的使用者出門清單，在開始新檢查前取消「展示檢查」勾選。兩者的確認都只是明確操作紀錄，不是獨立視覺持有量測。

## 分析新影片

首頁點 **分析新影片**，或側欄切到「新影片分析」。上傳 MP4、輸入找物問題、勾選使用 GPU，才會提交原 Phase 7 流程。預設上限 200 MB；先前 36.77 秒影片約需 12 分鐘。

可重新整理後從最近背景工作看實際階段與日誌。完成後「開啟這份記憶並搜尋」，再開啟出門檢查；新影片有自己的檢查，不會繼承另一份記憶的打包確認。

## 已知限制

這是使用者點擊啟動的離開助理。沒有自動出門偵測、忘帶偵測或實體持有確認；現有影片仍沒有 VERIFIED 位置。鑰匙／錢包感知效果未驗證，沒找到時保持 UNKNOWN／未確認。後台 GPU timeout 或失聯時沿用 Phase 8 的鎖與日誌處理，不盲目重試。

本機狀態：`artifacts/findmind_demo/checklist_state.json`。請透過 UI 開新檢查／管理設定；不要把確認寫進 `memory_graph.json`。證據與歷史檢查在展示重設時保留。
