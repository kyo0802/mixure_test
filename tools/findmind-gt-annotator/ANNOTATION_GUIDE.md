# 人工標註準則

## 1. 先看完整錄影

這是原片 GT 標註，不是對模型答案打分。工具不顯示模型預測、舊 GT 或預期事件。可以標全部九片，也可只完成指派子集；其他影片維持尚未開始。

## 2. 事件與其他觀察

- **PICKUP**：物件由表面支撐轉為被人持握；需實際可見支持轉移。
- **PLACEMENT**：由人持握轉為表面支撐；只有靠近桌面不足以證實。
- **CONTACT_ONLY**：接觸、觸碰或手靠近，沒有足夠證據證明拿起／放下。
- **CAMERA_MOTION_ONLY**：僅能看出視角改變，不能證明物件被搬動。
- **遮擋／證據不足**：無法確定是否有轉移。另在覆蓋頁記錄可能隱藏事件的不確定區間。
- **OTHER**：其他值得記錄的非確定觀察。

後四者不自動計為物理正例。沒有看見事件，不等於確定沒有事件。

## 3. 時間與證據

暫停近事件開始，按「設定開始時間」；看至事件結束再按「設定結束時間」。可手改來源秒數，不必猜單一精確影格。事件區間表示你能支持的物理轉移時間範圍，不是單純把 before/after 兩張圖的間隔當作動作持續時間。

在能證明前狀態的畫面按「加入目前時間至 Before」，在能證明後狀態的畫面按 After；可填多個時間。證據可在動作區間之前或之後，仍須在原片範圍且前後有序。

確定 PICKUP 的前／後為 ON_SURFACE → HELD_BY_PERSON；PLACEMENT 相反。若看不清後狀態，保留 UNKNOWN／不確定，不為了通過檢查猜答案。

## 4. 物件、實體與 State

類別可用 Phone、Keys、Wallet、Ball、Bottle、Box、Remote、Other 或自訂文字。同類多個實物可分 phone_01、phone_02；這些 ID **只在你的本片判斷中有效**，不會自動跨片合併成專案實體。不確定請用 UNKNOWN 並記錄身分把握。

State：ON_SURFACE、HELD_BY_PERSON、OTHER、UNKNOWN。可見度另選 VISIBLE、PARTIALLY_OCCLUDED、NOT_VISIBLE、UNCERTAIN。

不可見不代表物理不存在，也不能依較早持握推定遮擋期間仍持握。類別、顏色與外形相似不能單獨證明同一物理實體。未建立的 state 不是自動 UNKNOWN。

## 5. 覆蓋與不確定性

在覆蓋頁手動新增已審閱來源區間。編輯標註後，舊的完整性確認會撤銷，請重新檢查。

進度包含尚未開始、進行中、部分審閱、完成但有侷限、全片已刻意審閱。最後一項要求全長區間沒有缺口，並逐一確認：

1. 整段時間軸已刻意審閱。
2. 所有可辨識 PICKUP／PLACEMENT 已記錄。
3. 所有不確定／模糊區間已記錄。
4. 身分疑慮已保留，沒有猜測。

**全片已審閱仍不必然是完整事件清單。** 只有再明確確認沒有可隱藏額外事件的不可觀察缺口、目標關聯已釐清，且沒有未解事件／身分疑慮，才會得到 EXHAUSTIVE_ATTESTED。聲明只限 PICKUP／PLACEMENT，不涵蓋所有物理行為。

有遮擋可能藏事件時，在不確定區間勾「可能藏有事件」；身分疑慮也要記錄。這些會保留為非完整或未知，不會被當成未列事件的負例。

零事件的影片可完成審閱，但只有符合上述完整性條件並經主持人裁決才可作正式負例。匯出 FINAL 僅表示繳交，並不改變這些科學資格。

## 6. 多天工作與提交

每次儲存標註後會嘗試本機暫存；出現黃色警告時更應立即下載 JSON。離開前下載備份。續做時可選本機 session 或匯入 JSON。完成後匯出成果，將 JSON 傳給負責人；不需傳影片、安裝程式或推送 GitHub。
